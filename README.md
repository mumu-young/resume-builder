# 简历工坊（Resume Workshop）

> 纯本地、零依赖、完全离线的个人简历制作工具。

---

## 项目解决什么问题

做简历常见的痛点：

- **在线简历工具**要登录、联网，简历数据放在别人的服务器上，有隐私顾虑；
- **Word / PPT 手排**费时费力，改一处内容要重新调整排版；
- **模板太少或太死板**，很难做出适合自己的版式。

**简历工坊**把「填写内容 → 实时预览 → 选模板 → 导出成品」整合在一个纯本地网页里：**双击打开即用，数据只存在你自己电脑上，不联网、不登录、不上云**，免费、无广告、无需注册。适合任何需要做简历的求职场景。

## 主要功能

### 📦 13 个功能模块

| 模块 | 说明 |
| --- | --- |
| 基础信息 | 姓名、年龄、电话、邮箱、所在地、求职意向、工作年限、个人简介、照片 |
| 教育经历 | 学校、专业、学历、起止时间、绩点/排名、相关课程、描述，支持多条 |
| 实习 / 工作经历 | 公司、职位、起止时间、工作描述（多行），内置 STAR 写法提示 |
| 项目经验 | 项目名、角色、起止时间、技术栈、链接、描述 |
| 专业技能 | 按分类填写（编程语言 / 框架 / 工具等），支持多条 |
| 荣誉证书 & 附加信息 | 荣誉/证书列表 + 语言、兴趣爱好等补充信息 |
| 模块排序 | 调整五大模块顺序、编辑小标题内容、设置小标题/分割线颜色、粗细与显示 |
| 模板中心 | 9 套模板一键切换、实时生效 |
| 页面边距 | 调整简历上 / 右 / 下 / 左四周留白（单位 mm），可一键无空白或恢复默认 |
| 导出与打印 | 导出 A4 PDF（浏览器打印）、导出 Word（.docx，跟随模板、含照片） |
| 本地数据管理 | 自动保存、导出/导入 JSON 备份、清空数据 |
| 实用小工具 | STAR 写作助手、字数统计（分模块 + 总计 + 一页建议） |
| 全局系统设置 | 浅色 / 深色主题、简历正文字号（10–20px）、新简历默认模板 |

### ✨ 其它亮点

- **多份简历管理**：新建 / 复制 / 重命名 / 删除 / 切换多份简历，记住上次打开的那份。
- **9 套模板**：简洁单栏、经典两栏、现代简约、优雅知性、紧凑实用、经典模板、开放两栏、标题背景色、标题背景浅色。
- **模块排序与配色**：模块顺序可自由调整；小标题内容可编辑；小标题 / 分割线颜色、粗细、显示均可自定义（含黑色，黑底白字可读）。
- **照片**：本地上传，默认 7:9 矩形，可切换圆形；导出 Word 时嵌入照片。
- **联系信息灵活展示**：分隔符可选 `|` / `·` / 空白；每个字段可单独开关“显示标签”。
- **实时预览**：左侧编辑、右侧 A4 实时预览，可一键隐藏 / 显示（侧栏底部开关）。
- **导出 PDF**：浏览器打印导出 A4 PDF，背景图形可选。
- **导出 Word**：生成真正可编辑的 .docx，版式跟随当前模板（两栏 / 底色 / 标题样式），含照片、微软雅黑、A4 与边距按设置。
- **隐私优先**：完全离线，无任何网络请求。

## 安装方法

**零安装、零依赖**：只需要一个浏览器（推荐 Chrome / Edge）。

### 方式一：直接下载 / 克隆

```bash
git clone https://github.com/mumu-young/resume-builder
cd 简历制作app
start 简历工坊.html        # Windows；或直接双击 简历工坊.html
```

> 也可以把整个文件夹拷到任意电脑，双击 `简历工坊.html` 即可运行。

### 方式二：运行自动化测试（可选，需要 Node.js 18+）

```bash
node tests/run-tests.js
```

测试完全本地运行（Node + Edge 无头），不联网。

## 使用方法

1. **打开应用**：双击 `简历工坊.html`，用 Chrome / Edge 打开。
2. **填写内容**：左侧按模块填写——
   - 基础信息 → 教育经历 → 实习 / 工作经历 → 项目经验 → 专业技能 → 荣誉证书；
   - 右侧预览实时更新，所有修改自动保存。
3. **选模板**：进入「模板中心」，选择喜欢的模板（默认「经典模板」）。
4. **微调版式**：
   - 「模块排序」调整模块顺序、小标题内容与颜色、分割线颜色/粗细/显示；
   - 「页面边距」调整四周留白（默认 上10 / 右12 / 下10 / 左12 mm，开放两栏固定无空白）。
5. **导出成品**：
   - **PDF**：点「导出 PDF」，在打印窗口选「另存为 PDF」，纸张 A4、边距「无」、勾选「背景图形」；
   - **Word**：点「导出 Word（.docx）」，得到可继续编辑的 Word 文档。
6. **备份数据**：定期在「本地数据管理」点「导出全部数据备份（JSON）」存到别处，防止浏览器缓存被清理丢失。

## 数据存储与备份

- 所有数据实时自动保存到**本机浏览器**（优先 IndexedDB，异常时降级 localStorage）。
- 刷新、关闭浏览器、重启电脑都不会丢失。
- ⚠️ 浏览器缓存被清理会导致数据丢失，**建议定期备份**：「本地数据管理」→「导出全部数据备份（JSON）」；恢复时用「导入备份文件」（按简历 id 合并）。
- 「清空所有数据」会删除全部简历与设置（需二次确认），不可恢复。

## 技术栈与目录结构

原生 HTML + CSS + JavaScript，**零第三方依赖、零构建**；IndexedDB 本地存储；无头 Edge + Node 做自动化测试。

```
简历制作app/
├── 简历工坊.html            # 唯一入口，双击打开
├── README.md             # 本说明
├── PRD.md                # 需求文档
├── DEVELOPMENT_PLAN.md   # 开发计划
├── css/
│   ├── style.css         # 界面样式 + 浅色/深色主题 + 打印样式
│   └── templates.css     # 9 套简历模板样式
├── js/
│   ├── utils.js          # 通用工具函数
│   ├── storage.js        # 本地数据层（IndexedDB / localStorage）
│   ├── templates.js      # 9 套模板渲染器
│   ├── docx.js           # Word（.docx）导出：ZIP 写入 + 模板版式 + 照片嵌入
│   └── app.js            # 主应用逻辑（13 个模块）
└── tests/                # 自动化测试（Node + Edge 无头）
```

## 已知限制

- 只做电脑浏览器版，不适配手机端。
- 内置 9 套模板，暂不支持自定义模板编辑器。
- 无 AI 润色、无简历评分 / ATS 分析（与纯本地定位冲突）。
- Word 导出为“可继续编辑的结构化版式”，与网页模板的精细视觉效果存在差异（如圆角、复杂间距）；追求完全一致的成品建议用 PDF。
